# deployments/

Deployment tooling and per-network configuration for the Zeracle chain stack.
This directory (not the repo root) is the working directory for the task
runner — invoke it with `make -C deployments <target>` from anywhere, or `cd`
in and run `make <target>`.

## Layout

- `Makefile` — task runner (moved here from the repo root). Wraps the scripts
  below; `make -C deployments help` lists targets.
- `sandbox-local/` — everything the local stack owns:
  - `deploy-sandbox.sh`, `stop-sandbox.sh`, `install-mock-feeds.sh` — deploy/
    stop anvil + the Aztec sandbox + contracts on this machine.
  - `.env` — this environment's config (e.g. `MAINNET_RPC_URL` for anvil
    forking), auto-loaded by the scripts.
  - `deployment-manifest.json` — generated by `deploy-sandbox.sh` on every
    deploy: addresses, RPC endpoints, test accounts.
  - `start-fes.sh` / `stop-fes.sh` — dev frontend helpers (web, docs,
    chain-view).
- `sandbox-ec2/` — `deploy-ec2.sh`, a thin wrapper around the real EC2
  chain-host flow in `devops/production/ec2` (Terraform + tarball build +
  bootstrap). Builds the release tarball and prints the `terraform apply` /
  SSH-log-watch next steps; `--apply` also runs `terraform apply`. The
  contract deploy + mock feeds run ON the box at first boot via the SAME
  `sandbox-local/` scripts (shipped in the tarball, invoked headless by
  bootstrap.sh) — deliberately not duplicated here. See its README.
- `testnet/` — `deploy-testnet.sh` now runs a real, config-gated pipeline
  (preflight → Sepolia L1 → official Aztec testnet L2 → manifest/web-env
  sync); see `testnet/README.md` for prerequisites and usage.
- `mainnet/` — `deploy-mainnet.sh`: still a fail-loud stub (exit 1) until
  that migration starts. See its README and
  `docs/versions/260709/existing-limitations.md` (repo root) for the
  prerequisites.

Each environment dir owns its own deployment script(s), and the Makefile has
per-env targets: `deploy-sandbox-local` (alias `deploy`),
`deploy-sandbox-local-skip-infra` (alias `deploy-skip-infra`),
`stop-sandbox-local` (alias `stop`), `stop-clean`, `deploy-sandbox-ec2`,
`deploy-sandbox-ec2-apply`, `deploy-testnet`, `deploy-mainnet`. Run
`make -C deployments help` for the full list.

**Terminology:** sandbox != testnet. Both `sandbox-local` and `sandbox-ec2`
run the Aztec *sandbox* (single-node, local); "testnet" only ever refers to
the official Aztec testnet.
